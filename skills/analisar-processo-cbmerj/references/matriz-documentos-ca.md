# Matriz de evidências para CA

Esta matriz é índice de coleta; confirmar a redação na NT vigente e no LE/projeto.

| Tema | Evidência mínima a procurar |
| --- | --- |
| Linha de base | LE, PSCIP aprovado, aditamentos e atos posteriores |
| Declarações | responsável legal e RT no procedimento assistido |
| Responsabilidade | ART/RRT/TRT de instalação, inspeção, manutenção, ensaio ou laudo |
| Sistemas fixos | laudo circunstanciado, fotos identificadas e parâmetros |
| Extintores | notas fiscais/contrato, inspeção/recarga e certificação aplicável |
| Bombas | curva/tabela com fabricante, modelo, série, vazão, pressão, rotação, rotor e potência |
| Pressurização | relatório de teste/aferição e responsabilidade técnica |
| GLP/GN | estanqueidade, instalação, central/rede e responsabilidade |
| Cozinha/exaustão | instalação, limpeza/manutenção, sistema fixo e responsabilidade quando aplicável |
| Tanques/gerador | capacidades, instalação, contenção, abastecimento, ensaios e responsabilidade |
| Brigada/BVI/BC | contratos, credenciamentos, certificados e efetivo aplicável |
| Hidrante urbano | instalação/operação ou rito de inviabilidade/sobrestamento |
| Proteção passiva/TRRF | relatório de aplicação, espessuras, produtos, ensaios e responsabilidade |
| Unidade autônoma | LE/CA da edificação-base e compatibilidade da parte |

Para cada documento, testar objeto, endereço, data, validade, profissional/empresa,
atribuição, sistema e correspondência com o requisito do LE. Documento genérico não
comprova execução.
