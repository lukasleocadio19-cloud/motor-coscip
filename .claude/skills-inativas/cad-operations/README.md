# CAD Operations Skill

A portable Codex skill for local CAD automation workflows: electrical single-line diagrams, pavement structure drawings, AutoCAD/DXF deliverables, and SolidWorks MCP/COM guidance.

## What this repository contains

- `SKILL.md` — the triggerable Codex skill entry point and routing guide.
- `references/` — focused workflow notes for electrical SLD, pavement CAD, AutoCAD/FreeCAD, SolidWorks MCP, and local environment setup.
- `scripts/make_main_sld.py` — generate electrical main single-line diagrams as DXF, SVG, and PDF.
- `scripts/generate_pavement_cad_ezdxf.py` — generate AutoCAD-friendly pavement structure DXF files with `ezdxf`.
- `scripts/generate_pavement_cad.py` — dependency-light fallback pavement DXF generator.
- `examples/` — ready-to-run JSON specifications.
- `tests/smoke_test.py` — verifies sample generation and DXF readability.

## Quick start

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe tests\smoke_test.py
```

Generated files are written under `output/smoke/`.

## Generate an electrical SLD

```powershell
python scripts\make_main_sld.py examples\electrical_sld_spec.json --outdir output\sld --stem demo_sld
```

Outputs:

- `output/sld/demo_sld.dxf`
- `output/sld/demo_sld.svg`
- `output/sld/demo_sld.pdf`

## Generate a pavement structure DXF

```powershell
python scripts\generate_pavement_cad_ezdxf.py examples\pavement_structure_spec.json --out output\pavement
```

Optional AutoCAD open step:

```powershell
$env:AUTOCAD_EXE = "C:\Program Files\Autodesk\AutoCAD 2025\acad.exe"
python scripts\generate_pavement_cad_ezdxf.py examples\pavement_structure_spec.json --out output\pavement --open --acad $env:AUTOCAD_EXE
```

## Install as a Codex skill

Copy or clone this folder into your Codex skills directory:

```powershell
git clone https://github.com/2836048681/cad-operations-skill.git "$env:USERPROFILE\.codex\skills\cad-operations"
```

Restart Codex or refresh skills after installation.

## Optional local CAD integrations

This repository does not bundle proprietary CAD software. Configure local paths when available:

```powershell
$env:AUTOCAD_EXE = "C:\Program Files\Autodesk\AutoCAD 2025\acad.exe"
$env:ACCORECONSOLE_EXE = "C:\Program Files\Autodesk\AutoCAD 2025\accoreconsole.exe"
$env:SOLIDWORKS_MCP_HOME = "$env:USERPROFILE\.codex\mcp\SolidworksMCP-python"
```

SolidWorks MCP is documented in `references/solidworks-mcp.md`; the skill can use MCP when exposed by the client, or fall back to Windows COM/VBA/scripted workflows.

## Validation checklist

Before publishing CAD deliverables generated by this skill:

- Confirm requested output files exist and are non-empty.
- Validate DXF files with `ezdxf.readfile` when possible.
- Inspect SVG/PDF/PNG previews for label overlaps, missing glyphs, and connection mistakes.
- For SolidWorks, require live rebuild/status evidence plus native/exported files.
